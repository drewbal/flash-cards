# Слово

Личный англо-русский словарь и интервальные тренировки. PWA для iPhone,
без аккаунтов и серверной базы. Данные хранятся в IndexedDB на устройстве.

## Запуск

Node.js 22.12+ и pnpm 11.19.0:

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
```

Для проверки офлайн-режима используйте production-сборку (`preview`),
не dev-сервер. Service Worker требует HTTPS (или localhost).
На iPhone откройте опубликованную HTTPS-ссылку в Safari → Поделиться →
На экран Домой. В настройках приложения проверьте готовность офлайн.
Первоначальная загрузка словаря — примерно 16 МБ без HTTP-сжатия.

## Публикация

В GitHub Settings → Pages выберите Source: GitHub Actions. Workflow
`.github/workflows/pages.yml` собирает, тестирует и публикует ветку `main`.
Поддерживается размещение в подпапке репозитория благодаря относительным URL.
В этой рабочей копии публикация и push автоматически не выполнялись.

## Правила

- Карточка представляет выбранное значение; синонимы разделяются `;`.
- Независимые EN → RU и RU → EN. Интервалы: 1, 3, 7, 14 календарных дней
  по локальному времени от фактического успешного ответа.
- Ошибка / просмотр перевода сбрасывает соответствующее направление на завтра.
- Ошибки повторяются в конце занятия без повышения уровня.
- Ввод нечувствителен к регистру и пробелам. Одна вставка, удаление,
  замена или перестановка соседних букв в ответах длиной от 4 символов
  даёт возможность исправить опечатку без сброса.
- Просмотр карточки из коллекции раскрывает перевод и сбрасывает EN → RU.
  Изменение допустимых ответов сбрасывает оба направления.
- Поиск сам по себе не сбрасывает прогресс; перевод раскрывается отдельной кнопкой.
- Слово выучено после завершения обоих направлений.
- Последовательные направления одного слова разносятся, если в очереди есть
  другие слова; иначе показывается экран с предложением сделать паузу.

## Хранение и резервные копии

IndexedDB `slovo-flash-cards`, версия 1. Карточки и история сохраняются
атомарно. Экспорт JSON доступен в настройках. Импорт проверяет структуру
и требует подтверждения замены. Очистка данных сайта удаляет коллекцию.
Синхронизации между устройствами нет. На одном браузерном профиле — одна коллекция.
Параллельные изменения в другой вкладке обнаруживаются при сохранении:
приложение предлагает перезагрузить страницу, не перезаписывая новые данные.

Service Worker сохраняет весь словарь и приложение. Каждая сборка получает
свой cache ID; новая версия активируется после закрытия старых окон приложения.

## Словарь и лицензия

English–Русский FreeDict+WikDict, версия 2025.11.23, 62 181 статья,
78 720 групп значений. Maintainer: Karl Bartel.
Данные Wiktionary.org через DBnary; автоматически собраны WikDict.

- Источник: https://freedict.org/downloads/
- Архив: https://download.freedict.org/dictionaries/eng-rus/2025.11.23/freedict-eng-rus-2025.11.23.src.tar.xz
- Лицензия базы и производной JSON-базы: CC BY-SA 3.0.
- Полный текст: `public/dictionary-LICENSE.txt`.

Воспроизведение преобразования:

```sh
python3 scripts/prepare_dictionary.py /path/to/freedict-eng-rus-2025.11.23.src.tar.xz
```

Изменения: TEI → JSON, снятие ударений, очистка wiki-ссылок, удаление
дублей в группах переводов. Смысловые ошибки исходной базы не исправлялись.
Пояснения часто английские. Поиск словоформ использует ограниченный набор
исключений и эвристики; это предложения, а не полноценный морфологический анализ.
Русский поиск строится по переводам англо-русской базы, а не по отдельному русско-английскому словарю.

## Проверки

`tests/core.test.ts` проверяет расписание, просрочки, независимый прогресс,
опечатки, очередность и валидацию резервных копий. Перед публикацией полезна
проверка на физическом iPhone: установка, клавиатура, офлайн-запуск,
экспорт в «Файлы» и восстановление.

Проверено локально: production-сборка, 7 автоматических тестов, браузерный
сценарий поиска и добавления, импорт копии, исправление опечатки, оба
направления, повтор ошибки, сохранение после перезагрузки. При остановленном
сервере проверены перезапуск приложения и поиск из кэша. Интерфейс осмотрен
при ширине 390 px. Физический iPhone ещё не проверен.
